# 🍡 Mochi Portfolio

Welcome to **Mochi Portfolio** — a personal portfolio website project designed to showcase creativity, skills, projects, and personal achievements in one place.

## ✨ About the Project

Mochi Portfolio is a web development project focused on creating a personal online space to present information about the creator, highlight projects, and make it easier for visitors to explore their work.

## 🚀 Features

- **Personal Introduction** — Introduce yourself and share your background.
- **Skills Showcase** — Highlight technical skills and areas of interest.
- **Projects Section** — Display projects and development work.
- **Responsive Design** — Aim to provide a smooth experience across different screen sizes.
- **Simple Navigation** — Help visitors explore the portfolio easily.

## 📂 Getting Started

Follow these steps to run the project locally.

1. Clone the repository:

   ```bash
   git clone https://github.com/na-debug/Mochi-Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Mochi-Portfolio
   ```

3. Open the `index.html` file in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code if the project supports it.
